# 论文速读：The-Geometry-of-Inference-in-Transformer-Residual-Streams

## 一句话总结
本文提出"几何推理假设"，通过构建固定端点库（其他上下文的最终残差状态）来度量 Transformer 中间残差状态对自身终点的几何特异性，揭示推理过程中方向对齐与竞争者削减的非线性耦合机制，并证明结构化端点分布可预测沿未见轨迹的竞争动态。

## 研究问题与动机
- Transformer 通过连续残差更新构建下一个 token 预测，但中间残差状态如何逐步变得对最终预测终点具有特异性尚不明确。
- 现有预测透镜（prediction lenses）证实中间状态包含预测信息，但未刻画"某一中间状态在多少替代终点中仍具竞争性"这一选择性演化过程。
- 仅测量到自身终点的距离无法区分"接近平均替代者"与"显著区别于个别替代者"两种几何特异性。
- 不同距离度量（欧氏 vs. 余弦）对推理特异性演化的刻画可能给出互补甚至矛盾的信号，需系统比较。

## 核心贡献（创新点）
1. **提出基于终点的推理几何探针**：用固定端点库记录其他上下文的最终残差状态，定义欧氏/余弦意义下的竞争者集与竞争者比例，量化中间状态对自身终点的选择性。
2. **揭示方向对齐与距离平台的解耦现象**：证明在规范化欧氏距离保持恒定的路径上，余弦对齐仍可单调改善；通过高维共享轴模型解释"平均偏好早现而个体竞争者众多"的并存机制。
3. **证明直线路径产生嵌套竞争者集**：在固定端点库下，沿直线单调收敛至自身终点的轨迹在欧氏与余弦距离下均保持嵌套竞争者集，观测到的 entry 构成对单调直线收敛的违反证据。
4. **建立端点分布几何与竞争质量的定量联系**：将期望竞争者数表达为比较区域（球/球冠）内的端点概率质量，并用五类方向分布模型（均匀球、球冠、单 vMF、vMF 混合、投影正态）拟合端点方向结构。
5. **展示结构化端点分布可外推预测未见轨迹上的竞争分数**：在五个模型上，投影正态模型以最低 log-scale 误差预测余弦竞争者比例曲线，显著优于均匀球基线（提升 4.6–7.5 倍）。

## 方法详解
- **距离度量**：欧氏距离 $d_E(x,y) = \|x-y\|_2$，余弦距离 $d_C(x,y) = 1 - \frac{x^\top y}{\|x\|_2\|y\|_2}$；欧氏轨迹距离按自身终点范数 $R_i = \|y_i\|_2$ 规范化。
- **竞争者集与比例**：$\mathcal{C}_{\ell,i}^{(m)} = \{j \in \mathcal{B}_i : d_m(x_{\ell,i}, y_j) < d_m(x_{\ell,i}, y_i)\}$，竞争者比例 $A_{\ell,i}^{(m)} = |\mathcal{C}_{\ell,i}^{(m)}|/M_i$，严格检索秩为 $1 + |\mathcal{C}_{\ell,i}^{(m)}|$。
- **平均偏好边界**：$\Delta_{\ell,i}^{(m)} = \frac{1}{M_i}\sum_{j\in\mathcal{B}_i} d_m(x_{\ell,i}, y_j) - d_m(x_{\ell,i}, y_i)$，正值表示自身终点比平均替代终点更近。
- **输入 token 与文档控制**：排除同文档替代者、匹配最终输入 token 子库、去除输入 token 嵌入方向投影，验证早期偏好不依赖共享文档或单一 token 身份。
- **竞争力质量（competitive mass）**：$q_{\ell,i}^{(m)} = \mathbb{P}(d_m(Y, x_{\ell,i}) < d_m(y_i, x_{\ell,i}))$，期望竞争者数为 $M q_{\ell,i}^{(m)}$。
- **高维共享轴模型**：$y_j = R(\rho m + \sqrt{1-\rho^2}v_j)$，$x = r(b m + \sqrt{1-b^2}w)$，在单位球面上导出 $\mathbb{E}[N_<] = M \overline{F}_D(a)$，其中 $a = w^\top v_i$ 为替代者得分阈值；近似 $\overline{F}_D(a) \approx 1-\Phi(\sqrt{D}a)$ 解释小对齐即可大幅削减竞争者。
- **端点分布拟合与选择**：五种方向模型（uniform sphere、uniform spherical cap、single vMF、vMF mixture、projected normal）共享同一经验范数分布；用四个 KS 诊断（成对余弦相似度、成对欧氏距离、最近邻欧氏距离、到全局轴余弦相似度）在验证集上选择复杂度；训练/验证/测试按文档 60/20/20 划分。
- **轨迹竞争预测误差**：$\mathrm{err}_{\log} = \frac{1}{L-1}\sum_{\ell<L}|\log_{10}(\widehat{A}_\mathcal{M}(\ell)+\varepsilon) - \log_{10}(A(\ell)+\varepsilon)|$，$\varepsilon=10^{-3}$。

## 实验与结果
- **模型**：Gemma-2B、Gemma-7B、Qwen2.5-1.5B、Qwen2.5-7B、Mistral-7B、Llama-3-8B。
- **数据**：FineWeb sample-10BT，每模型 1,024 个不重叠 256-token 上下文。
- **主要结果**：
  - 所有六个模型在第一测量层即满足 $\Delta_{\ell,i}>0$（文档级单侧 t 检验 $p<10^{-3}$）。
  - 欧氏距离下五个模型在较深范围内仍保持数百个竞争者；余弦竞争通常更早下降，但存在持续的成员更替（entries 与 exits）。
  - 低概率 rank-k token 对应的替代端点在余弦距离下更远（六个模型均通过单调增长单侧检验）。
  - 投影正态模型在五个模型上取得最低余弦竞争分数预测误差（Table 3），vMF 混合在 Gemma-7B 上略优。
  - 结构化解构模型证明：令 $b=\rho=0$ 且 $r/R=2a$ 时，归一化欧氏距离恒为 1，而余弦距离单调下降，显示距离平台期可与方向改进共存。
  - 端点分布诊断误差较均匀球基线改善 4.6–7.5 倍（Table 2）。

## 局限性与未来方向
- 几何特异性不等于 token 概率校准，竞争者比例未作为概率解释。
- 竞争者集合依赖所构建的端点库规模与度量方式，库外泛化性未验证。
- 未解释残差更新的具体来源与时间机制，仅描述轨迹层面的几何演化。
- 端点几何仅解释模型输出变化的一部分，其余来自非几何因素。
- 观测到的成员更替未确立显式内部搜索过程，需干预实验验证因果角色。
- 未来可沿训练检查点追踪端点群体与残差轨迹的联合组织演化。

## 研究启发与可借鉴点
- **固定参考库+相对几何探针**：可用相同框架在其他架构（如 MoE、SSM）上评估推理特异性演化，跨架构比较"平均偏好出现深度"与"竞争者削减速率"。
- **直线路径嵌套性证明**：可作为基准检验任意 trajectory compression/shortcut 方法是否引入非单调几何行为。
- **竞争力质量分解**：将期望竞争者数分离为"轨迹决定的比较区域"与"端点分布决定的概率质量"，为表征剪枝或蒸馏提供理论指标。
- **投影正态/ vMF 混合拟合端点方向**：可迁移至任何需对高维表征群体进行方向建模的任务，提升对下游竞争/检索行为的预测力。
- **距离平台期-方向改进解耦**：提示在监控模型压缩或微调时，欧氏距离收敛曲线可能掩盖方向特异性进展，应同时报告余弦对齐指标。

## 关键术语表
- **Residual Stream（残差流）**：Transformer 每层输出累加到隐藏状态的残差路径，中间状态 $x_{\ell,i}$ 沿此流演化。
- **Endpoint（端点）**：上下文的最终残差状态 $y_i = x_{L,i}$，即该上下文推理轨迹的终点。
- **Competitor Set（竞争者集）**：在当前中间状态下比自身终点更近的替代终点集合 $\mathcal{C}_{\ell,i}$。
- **Competitor Fraction（竞争者比例）**：竞争者集大小与端点库大小的比值 $A_{\ell,i}$，衡量几何特异性。
- **Directional Margin（方向边界）**：$m^C_{ij}(x) = x^\top(u_i - u_j)$，决定余弦意义下 $j$ 是否竞争。
- **Competitive Mass（竞争力质量）**：比较区域（欧氏球/余弦球冠）内端点分布的概率质量，期望竞争者数为 $Mq$。
- **Straight-line Convergence（直线收敛）**：沿直线单调趋近自身终点的路径，其竞争者集在两种度量下均嵌套。
- **Projected Normal（投影正态）**：对高斯样本作 L2 归一化的方向分布族，捕捉端点方向的各向异性。
