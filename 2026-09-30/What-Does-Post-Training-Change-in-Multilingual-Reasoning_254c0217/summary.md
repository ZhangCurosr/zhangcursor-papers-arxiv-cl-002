# 论文速读：What-Does-Post-Training-Change-in-Multilingual-Reasoning

## 一句话总结
本文对 Qwen3 系列模型在 11 种语言下的数学推理能力进行系统化阶段审计，揭示了从发布版检查点到多语言 SFT 再到强化学习（RL）各阶段的瓶颈转移规律，并提出了"正确性门控奖励"的 RL 设计以最终实现可靠的多语言端到端交付。

## 研究问题与动机
- **问题定义**：当模型能够解题但无法用用户请求的语言输出完整解时，语言成为"访问障碍"而非单纯的性能波动——现有 final-answer 准确率指标掩盖了高达 94 个百分点的"正确但未交付"差距。
- **现有研究的不足**：先前工作各自记录了多语言准确率缺口、目标语言遵从性、效率与可靠性等问题，但往往在不同系统或孤立训练阶段上观察，无法揭示某一训练阶段的主导瓶颈是什么、干预后瓶颈如何转移、修复代价为何。
- **评估指标的缺失**：标准评测通常只报告 C@k（正确率），无法同时追踪 L（语言遵从）、T（终止）及其联合指标 J = C ∧ L ∧ T，导致不同失败模式（解不出、用英语推理、开始但未完成）被混淆。
- **研究缺口**：没有一个工作在同一家族模型、固定评测协议下，纵向追踪 released checkpoint → SFT → RL 全阶段的瓶颈演化，本文旨在填补这一空白。

## 核心贡献（创新点）
1. **提出以交付为中心的评价框架 J = C ∧ L ∧ T**：同时报告正确率、语言遵从性、终止率及其联合指标，暴露最多 94 个百分点"正确但未交付"的性能差距，与以往仅报告准确率的评测形成本质区别。
2. **诊断 SFT 引入的双重代价**：证明多语言 SFT 恢复目标语言推理的同时会带来精度下降（非多语言特有，单语 SFT 对照组同样出现）和目标语言非终止循环（non-terminating loops），首次将"精度成本"与"循环故障"分离并分别归因。
3. **提出正确性门控奖励（correctness-gated reward）的 RL 设计**：仅奖励正确性会导致模型回退到英语；仅在奖励中加入语言 bonus 会被错误答案骗取；门控设计（R_gate = C_tr × (0.7 + 0.3ℓ_tr)）使语言奖励必须通过正确解题才能获得，从而在不损失精度的同时保持语言遵从。
4. **构建了一条从英语偏向能力到可靠多语言交付的建设性 post-training 路径**：SFT 修复遵从性→RL 恢复终止→门控奖励锁定精度与语言，三个阶段依次解除前一阶段的条件限制，形成可复现的训练路线图。
5. **引入交付效率（delivery efficiency）度量**：以每 1,000 token 的联合成功数为指标，考虑编码调整（encoding-adjusted）与原始 token 两种口径，揭示多语言端到端成本主要由"无效尝试"而非"有效解的长度"决定。

## 方法详解
- **评测协议**：在 70 道竞赛数学题（30 AIME-2026 + 40 AMC-2023）上，覆盖 6 种联合国官方语言（EN、ZH、ES、FR、AR、RU）及额外 5 种训练语料中不存在的语言（IS、SV、SW、TA、UR），每道题 16 次采样（temperature=0.7），响应预算 24,576 token。
- **三维度评估指标**：C（最终答案正确，用 math_verify 验证）、L（可见推理迹语言遵从，用 langid 判断≥50%片段为目标语言）、T（正常终止，不以重复分数>0.85 或达到 token 上限为失败）。联合指标 J = C ∧ L ∧ T（公式 1）。
- **多语言 SFT 数据集构造**：基于 45K OpenR1 英文长 CoT 数学迹，使用 Qwen3-14B 翻译为 5 种目标语言（经 Hunyuan-MT-7B 对比验证更优），经过 7 道质量门控（结构完整性、\boxed 答案保留、脚本纯度等），4B 使用 43,218 条迹，8B 使用 56,307 条独立构建的迹。
- **控制实验**：English-only SFT（9,800 条）、5 个单语言 specialist（各 9K–10K 条），用于分离多语言混合效应与一般 SFT 效应。
- **RL 训练设计**：基于 PPO，使用三种奖励 formulation（公式 2）：
  - R_corr = C_tr（仅正确性控制）
  - R_add = 0.7·C_tr + 0.3·ℓ_tr（加法阶段，错误答案也可获得语言奖励）
  - R_gate = C_tr × (0.7 + 0.3·ℓ_tr)（门控阶段，正确性为必要条件）
- **交付效率度量**：joint_per_lk(ℓ) = 1000 × #J=1 / #adjusted_tokens，并以非英语效率相对于同 check point 英语效率归一化（公式 3），100% 表示 parity。

## 实验与结果
- **发布版基线**：Qwen3-4B 在非英语五语平均 C@16 = 90.6%，但 J@16 仅 35.7%；Qwen3-8B 为 C@16 = 92.6%，J@16 = 30.6%。英语同为 ~92.9%，差距完全由语言选择导致。
- **扩展语言（训练集外）**：10 种非英语语言上，4B 达到 C@16 = 84.3%，J@16 仅 17.9%；8B 为 89.0% vs 15.4%。瑞典语在 8B 上差距最大（C@16 = 94.3%，J@16 = 0%）。
- **SFT 后改善**：4B J@16 从 35.7% 提升至 84.6%，语言遵从 L 从 39.8% 升至 99.4%；8B 从 30.6% 升至 86.3%。但精度下降约 5–6 个百分点，且非英语终止失败率从 4.7% 升至 21.1%（主要由检测到的循环引起）。
- **RL 后最终结果**：
  - 仅正确性 RL：J@16 降至 15.4%，语言遵从骤降至 8.7%（模型回退到英语）。
  - 门控 RL（最佳）：J@16 达 81.7%，L = 99.8%，非英语终止失败仅 0.5%，精度 C@1 = 60.1%，与正确性控制臂持平。
  - 交付效率从 SFT 后的 73%（相对英语）提升至 102%，条件于成功交付时接近parity（J-only adjusted: 117%）。
- **最强结果**：Qwen3-4B + 多语言 SFT + 门控 RL，五语平均 J@16 = 81.7%，相比发布版提升 46 个百分点，相比仅正确性 RL 提升 66 个百分点。

## 相关工作脉络
1. **英语中心化内部表征研究**（Wendler et al. 2024; Schut et al. 2025）：发现模型内部表征偏向英语，本文从"可见推理迹"层面验证了这一现象在实际输出中的严重性（最高 94% 的正确解被英语"掩盖"）。
2. **长 CoT 跨语言推理**（Barua et al. 2026; Tam et al. 2025）：先前工作分别描述了英语主导与非目标语言推理迹，本文首次在单一模型家族中纵向追踪这些现象在不同训练阶段的演变。
3. **翻译障碍假设**（Bafna et al. 2025; Kang et al. 2026）：先前研究将多语言差距归因于输入/输出端的隐式翻译失败，本文证明即使有完整的目标语言数据，SFT 仍会引入循环故障，归因更为精细。
4. **多语言 RL 方法**（Zhan et al. 2026; Fan et al. 2026; Gururov et al. 2026）：先前工作使用一致性增强目标或语言适应提示，本文的核心发现是：奖励设计中语言项是否被正确性门控决定了模型是否真正交付目标语言解，而非简单拼接语言 bonus。
5. **Polymath 与 MTM-Bench**（Wan et al. 2025; Zhan et al. 2026）：已有工作提出 per-language 准确率和语义-语言分解评测，本文在此基础上进一步引入终止维度 T 和端到端交付效率，填补了可靠交付评估的空白。
6. **推理模型的循环故障**（Pipis et al. 2026）：先前观察到推理模型会陷入重复循环消耗预算，本文首次将此现象与多语言 SFT 直接关联，证明目标语言推理比英语更易产生循环。

## 局限性与未来方向
- 结论仅适用于 Qwen3 家族和竞赛数学任务，发布于已进行过充分数学 post-training 的 check point 之上，干预目标是交付而非通用推理能力泛化。
- 每个训练 run 仅使用一个 seed，评测限于 70 道翻译题目，English-only 与 specialist 控制实验在数据量和训练配置上存在差异，比较偏诊断性而非完全因果匹配。
- 翻译可能改变数学问题的自然表达或难度，尽管通过高相关系数（均值 r=0.907）和翻译质量门控进行了缓解。
- 未处理"自信的错误答案"可能误导用户的问题——终止修复后模型可能输出流畅但错误的目标语言解答。
- 未来方向：将门控 RL 设计推广到更多任务类型和更多语言、探索更长周期的 RL 训练、开发防止自信错误答案的额外安全机制。

## 研究启发与可借鉴点
1. **J = C ∧ L ∧ T 联合评估框架可直接迁移**：适用于任何需要"正确+目标语言+完整输出"的多语言应用系统评估，优于单一准确率指标。
2. **控制实验设计值得借鉴**：通过 English-only SFT 和单语言 specialist 对照，成功分离了"多语言混合"与"一般 SFT 效应"，这种诊断性实验设计可用于其他 post-training 研究。
3. **正确性门控奖励设计可复用**：R_gate = C × (α + β·ℓ) 的设计避免了语言奖励被错误答案骗取的问题，该形式可推广至其他需要同时优化任务性能与格式/语言约束的 RL 训练场景。
4. **交付效率（delivery efficiency）度量具有普适价值**：将"所有尝试的 token 成本"纳入评估，揭示了无效尝试而非有效解长度是多语言成本的主要来源，为系统级部署决策提供了新视角。
5. **瓶颈逐阶段转移的发现模式**：揭示"修复一个瓶颈后另一个瓶颈成为主导"的规律，可作为多阶段训练系统的通用分析框架，指导后续的干预顺序选择。

## 关键术语表
- **Deliver（交付）**：指模型在请求语言中输出正确且完整的解决方案（C ∧ L ∧ T 同时满足），而非仅最终答案正确。
- **Language adherence（语言遵从性）**：可见推理迹中≥50% 文本片段被分类为目标语言的程度。
- **Termination failure（终止失败）**：模型生成超过 token 上限或进入检测到的重复循环而未正常结束。
- **Correctness-gated reward（正确性门控奖励）**：RL 奖励设计中，语言 bonus 仅在答案正确时才被激活的乘法门控形式（R = C × (0.7 + 0.3ℓ)）。
- **Delivery efficiency（交付效率）**：每 1,000 生成 token 产生的联合成功（J=1）数量，反映端到端资源成本。
- **Pass@k（pass@K）**：k 次采样中至少一次成功的无偏估计，本文使用 k=1 和 k=16。
- **OpenR1**：Hugging Face 维护的 DeepSeek-R1 完全开源复现项目，提供长 CoT 数学推理迹。
- **DAPO-Math-17K**：用于 RL 训练的 17K 道数学 prompt 数据集，按语言轮转分配。

## 可复现要素
- **数据集**：70 道竞赛数学题（30 AIME-2026 + 40 AMC-2023），翻译成 6 种语言；OpenR1 45K 数学推理迹；DAPO-Math-17K。论文未明确说明原始题目的开源状态，但提到所有生成的推理迹和样本级测量随 artifact 公开。
- **代码**：论文附录 B.5 声明分析脚本独立、参数无关、输出机器可读，随 accompanying artifact 公开；case page 和图表生成脚本也已开源。
- **权重**：基于 Qwen3-4B 和 Qwen3-8B 发布版 checkpoint，所有 SFT 和 RL 端点随 artifact 提供。
- **关键超参**：SFT 学习率 2×10⁻⁵，cosine decay；PPO clip ratio 0.2，γ=λ=1，actor LR 1×10⁻⁶，critic LR 1×10⁻⁵，response cap 16,384 token（门控阶段 8,192），batch size 32/64。
