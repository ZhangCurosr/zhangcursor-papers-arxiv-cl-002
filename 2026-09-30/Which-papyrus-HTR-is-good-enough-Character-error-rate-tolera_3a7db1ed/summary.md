# 论文速读：Which papyrus HTR is good enough? Character-error-rate tolerance of four papyrological tasks on Greek texts

## 一句话总结
本研究为希腊纸莎草纸手写文本识别（HTR）系统建立了一个下游任务容错率基准，通过合成不同字符错误率（CER）的文本，评估了其在文档类型分类、断代、文献/公文判别和关键词搜索四个古文书学任务上的表现。核心发现是：不同任务的容错度差异显著，且使用带噪文本对下游模型进行微调/重训练可大幅提升其在高CER下的性能。

## 研究问题与动机
1.  **核心问题**：对于特定古文书学任务，希腊纸莎草纸HTR系统需要达到多高的准确率（即允许多高的CER）才“够用”？
2.  **现有方法不足**：过往的HTR工作（如ICDAR 2023竞赛、Anagnostes系统）仅报告CER作为性能指标，但未评估该错误率对实际下游研究任务的影响。
3.  **领域特异性**：纸莎草纸文本具有连写（scriptio continua）、文本缺漏（lacunae）、片段极短、公文语言高度公式化等特点，这些因素对OCR噪声的容忍度尚未被研究。
4.  **实践需求**：绝大多数已出土的希腊纸莎草纸（估计100-150万片）尚未出版，自动转录的初步文本层若能支持快速筛选和分类，将极大释放专家精力，用于处理最重要的材料。

## 核心贡献（创新点）
1.  **定义了“完美HTR”文本标准**：提出了一套从EpiDoc XML学术版本中提取仅包含“墨水”（即抄写员所写）字符的规则，剥离了编辑层的复原、缩写展开、正字法标准化等，为模拟HTR输出提供了可靠的干净基线。
2.  **开发了精确可控的文本退化算法**：设计了一个合成算法，能在保证总Levenshtein距离精确等于目标编辑次数的约束下，生成指定CER的带噪文本，并分离了字符错误与整行丢失两种噪声模式。
3.  **建立了针对古文书学任务的首个CER容错基准**：首次在63,846份希腊纸莎草纸文献上，系统性地量化了四个核心任务（T1-T4）对HTR错误率的容忍阈值。
4.  **揭示了重训练的关键作用**：证明了对于文档类型分类等任务，在带噪文本上重新训练模型可以消除大部分性能衰减，使当前HTR系统（CER约10-20%）的输出变得有用。

## 方法详解
1.  **数据预处理（L0 → L3）**：
    *   从`papyri.info`数据库获取66,591份DDbDP和6,032份DCLP的EpiDoc XML版本文本。
    *   **L0（版本）**：原始学术编辑文本。
    *   **Ink-only（仅墨水）**：移除编辑复原、拼写规范化等，保留抄写员所写内容，用`□`标记缺文。
    *   **L3（纯字母）**：进一步标准化为小写、去除变音符号、标点、数字，仅保留24个希腊字母及3个古数字字母，保留换行符但移除词间距。此被视为“理想HTR”输出。
2.  **受控退化（Degradation）**：
    *   对L3文本应用合成噪声，目标CER为c = 0, 1, 2, 3, 5, 7.5, 10, 12.5, 15, 17.5, 20, 25, 30, 40, 50%。
    *   编辑预算K = round(c × N)，N为保留行的字母总数。
    *   编辑操作按3:1:1的概率比例随机选择替换、插入、删除。
    *   独立模拟10%, 20%, 30%的文本行丢失率，以区分字符错误与布局分析失败的影响。
    *   所有随机种子固定，保证结果可复现。
3.  **下游任务模型**：
    *   **四种任务**：T1文档类型/子类型分类、T2断代（回归至HGV日期的中点）、T3公文/文学文献二分类、T4关键词检索。
    *   **四类模型**：TF-IDF + 逻辑回归/岭回归、fastText、字符级CNN（Char-CNN）、预训练的ByT5-small。
    *   **两种训练范式**：R-clean（在干净文本上训练，测试各CER）；R-matched（在目标CER的带噪文本上重新训练）。
4.  **评估指标**：
    *   主要指标：宏观F1（分类）、MAE（断代）、Recall@20/MRR/nDCG（检索排序）、Micro F1（检索过滤）。
    *   核心分析：绘制指标随CER变化的曲线，计算“保留率”（M(c)/M(0)），并确定保持90%或95%性能的最大CER阈值（c90, c95）。

## 实验与结果
1.  **数据集**：63,846份希腊纸莎草纸文献（57,814份公文+6,032份文学/亚文学），共1860万字母。按文献组划分训练/验证/测试集（80/10/10）。
2.  **关键结果与CER阈值（保持90%性能的上限）**：
    *   **T3 公文/文学分类**：最鲁棒，**CER高达20%**。TF-IDF在20% CER时仍保持0.852的macro-F1。
    *   **T1 文档类型分类**：**CER 7.5%-12.5%**。干净训练的TF-IDF在12.5% CER时保持90%性能；经重训练后，容错率提升至15% CER，且在30% CER时性能（0.703）远高于干净训练的崩溃结果（0.163）。
    *   **T4 关键词搜索**：**CER 5%**（对长度≥10字母的查询）。基于最小编辑距离的排序方法最稳健，误差随CER线性下降。BM25等词频加权方法对噪声更敏感。
    *   **T2 断代**：最脆弱，仅**CER 3%**。即使完美转录，文本信息也难以稳定达到世纪级精度（MAE约55-83年）。重训练帮助有限。
3.  **主要结论**：
    *   任务对噪声的容忍度差异近一个数量级。
    *   对于分类和搜索任务，高CER（15-30%）下的性能崩溃主要源于训练-测试分布不匹配，重训练可有效恢复。
    *   片段长度是关键因素：短片段（<20字母）即使无噪声也接近随机；长片段（>500字母）可耐受更高CER。
    *   丢失整行比引入相同CER的字符错误对分类任务的影响小得多，但对检索的影响更大。

## 相关工作脉络
1.  **Greek Papyrus HTR/OCR**：ICDAR 2023竞赛及Anagnostes系统报道了约10-18%的CER，但本研究指出这些工作未回答“该准确率对具体研究任务有何意义”。
2.  **古文书学计算语言学**：如Ithaca模型依赖精心编辑的文本进行完形填空和断代，假设输入是干净的，而本研究直接测试从有噪声的HTR输出中进行同类任务。
3.  **OCR噪声对下游任务的影响**：大量研究考察了现代/近代印刷品OCR噪声对数字图书馆检索、命名实体识别、语言模型的影响，但本研究填补了针对纸莎草纸特殊文本特征（无空格、缺文、短片段、公式化语言）的空白。
4.  **文本分类与检索基线**：研究使用了TF-IDF、fastText、Char-CNN、BM25、编辑距离等经典方法作为基准，证明了在特定领域（低资源、非标准文本）中小模型配合正确训练策略可以非常有效。

## 局限性与未来方向
1.  **噪声模拟的局限性**：使用随机替换/插入/删除模拟噪声，而非真实HTR系统的错误模式（如特定字母混淆、字体影响、损伤模式）。研究声称其变体已涵盖真实错误的范围，但阈值需待真实HTR输出可用后重新校准。
2.  **噪声类型的简化**：仅建模了字符错误和整行丢失，未考虑行合并、顺序错误、跨页碎片错误拼接等更复杂的识别错误。
3.  **模型规模较小**：使用的模型（除ByT5-small外）均为自训练的小型模型。更大规模的预训练模型（如多语言LLM）的鲁棒性尚不明确，尽管重训练的有效性可能同样适用。
4.  **语言限制**：目前仅针对希腊语纸莎草纸。拉丁语和科普特语纸莎草纸的相同研究正在进行中。
5.  **任务覆盖有限**：未评估文学归属、学术文本重建等需要更深语言学理解的复杂任务。

## 研究启发与可借鉴点
1.  **下游任务驱动的评估范式**：强烈建议HTR研究不仅报告CER/WER，还应建立针对目标下游任务（如分类、检索、实体识别）的“任务就绪CER阈值”，使评估更具实用价值。
2.  **合成噪声与重训练策略**：当真实带噪平行数据稀缺时，使用精确控制的合成噪声对模型进行重训练，是提升其在高错误率下实用性的低成本高效策略。
3.  **噪声类型解耦分析**：将字符错误、缺失行、碎片长度等因素分开建模和评估，能提供更精细的性能洞察，指导前端系统（布局分析 vs. 识别）的改进优先级。
4.  **领域特定的文本标准化**：为纸莎草纸定义“纯墨水”文本视图的规则，对其它有复杂编辑传统的古籍（如碑铭、中世纪手稿）的HTR评估具有借鉴意义。
5.  **长度感知的性能报告**：建议根据片段/文档长度分层报告性能，因为短文本和高噪声的交互效应是关键瓶颈。

## 关键术语表
*   **HTR (Handwritten Text Recognition)**：手写文本识别，将手写文档图像自动转换为机器可读文本的技术。
*   **CER (Character Error Rate)**：字符错误率，基于Levenshtein编辑距离衡量的文本识别准确性指标。
*   **EpiDoc**：一种基于TEI XML的编码标准，专门用于编辑和发布古代铭文与纸莎草纸文献。
*   **scriptio continua**：连写法，古代书写中词与词之间没有空格分隔的样式。
*   **lacuna**：缺文，指文献中因载体损坏而缺失的文字部分。
*   **DDbDP / DCLP**：德克萨斯州杜克大学出版的《文献纸莎草纸数字数据库》和《文学纸莎草纸数字 corpus》，是希腊纸莎草纸文本的主要公开来源。
*   **Grammateus**：一个旨在对希腊公文纸莎草纸进行形式类型分类的项目。
*   **HGV (Heidelberger Gesamtverzeichnis)**：海德堡希腊纸莎草纸综合目录，提供文献的元数据，包括断代区间。

## 可复现要素
*   **数据集**：公开。来自`papyri.info` (`idp.data` repo, commit `fd88c0c`)的DDbDP和DCLP版本，Grammateus分类，Preisigke词典OCR文本。已提取并清洗。
*   **代码**：完全开源。https://github.com/repushko/good_enough_papyrus_htr。包含从EpiDoc提取、文本标准化、精确CER退化、所有模型、检索方法和分析的全部参考代码。
*   **模型权重**：论文中自训的小模型权重随代码发布。
*   **关键超参**：
    *   TF-IDF: 字符1-5-gram，子线性TF，l2归一化。
    *   fastText: 字母3-5-gram，dim=100-200，bucket=2M。
    *   Char-CNN: 64维字符嵌入，k=7卷积核，三阶段膨胀卷积(256通道)，最大+平均池化，输入长度≤4096字母。
    *   ByT5-small: 预训练字节级Transformer编码器，mask mean pooling + 线性头，输入≤2048字节。AdamW优化器。
    *   退化算法：编辑类型概率比 替换:插入:删除 = 3:1:1，非相邻位置编辑，gap token不受影响。
