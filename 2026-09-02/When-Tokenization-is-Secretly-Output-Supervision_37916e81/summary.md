# 论文速读：When Tokenization is Secretly Output Supervision

## 一句话总结
本文提出“分词即输出监督”的理论视角，证明自回归语言模型中输出 token 粒度决定了单次前向传播的监督单元与学习问题结构，并通过输入/输出分词解耦实验证实任务性能、训练动态与内部表示均由输出分词驱动；文献扫描揭示当前数值推理研究中近七成跨模型对比未披露分词策略，存在将任务定义差异混同为推理能力的系统性风险。

## 研究问题与动机
- **分词视角的片面性**：自回归语言模型普遍将 tokenization 视为输入预处理/表征决策，忽视了其在 next-token prediction 训练中同时定义输出监督粒度的本质。
- **性能差异缺乏机制解释**：已有工作反复观测到分词粒度显著影响算术、代码、时序等领域的模型表现，但仅停留在经验记录，未回答“为何分词会影响学习难度与内部表示”。
- **最小计算假设的缺失**：训练损失的梯度奖励仅作用于当前输出 token，模型是否会在无直接监督压力下主动构建超出当前步需求的内部表示，尚未得到系统检验。
- **学术报告规范的系统性盲区**：大模型基准对比日益普遍，但跨模型评估常忽略输出监督 regime 的差异，导致性能归因可能混淆了“任务难度”与“模型能力”。

## 核心贡献（创新点）
1. **提出“输出监督”（output supervision）概念框架**：将分词粒度重新定义为自回归训练的监督单元，阐明不同分词策略构造的是结构不同的学习任务，而非仅输入表征的变体。
2. **设计输入/输出分词解耦的 2×2 因子实验**：首次在数据层面独立控制输入与输出 tokenization，并用交叉熵损失掩码隔离监督信号，实证证明性能差异完全由输出分词驱动。
3. **提出并验证“最小计算假设”**：通过探针证明模型内部表示严格受输出梯度奖励约束，仅在任务强制依赖（如进位前瞻）下才被动编码未来信息，揭示了梯度奖励与任务需求之间的张力。
4. **揭示学界报告实践的结构性缺陷**：扫描 120 篇近期 *CL 数值推理论文，指出仅 9.2% 披露分词策略、69% 在未控制 regime 的情况下进行跨模型比较，并提出将分词作为标准模型描述符的方法论建议。

## 方法详解
- **理论推导**：在自回归训练中，每一步损失仅监督下一个输出 token。整体分词（holistic，如 `Llama 3`、`Pythia` 将三位数编码为单 token `[578]`）要求模型一次性联合解析所有子成分，损失无部分信用分配；分段分词（fragmented，如 `Qwen 2`、`Mistral`、`Gemma 2` 逐位编码 `5, 7, 8`）将任务分解为三步，每步获得位置特定的梯度奖励。两者共享同一 untokenized ground truth，但监督结构截然不同。
- **最小计算假设（Minimal Computation Hypothesis）**：模型仅解析输出监督所直接要求的计算内容，在无梯度压力时不会主动构建超出当前监督需求的表示。由此可证伪地预测：碎片化输出模型在生成第一位后，后续位的内部表示应维持随机水平。
- **解耦实验设计**：训练 4 组 4 层 decoder-only transformer（约 3.4M 参数），共享 1003 token 词表（整数 0–999 及 `+, =, PAD`）。通过 2×2 因子设计构造 $M_F$（碎片输入/输出）、$M_H$（整体输入/输出）、$M_{F_{in},H_{out}}$、$M_{H_{in},F_{out}}$。交叉熵损失仅计算 `=` 之后的输出 token，实现输入表征与监督信号的完全解耦。
- **探针与消融**：在 `=` token 位置的 residual stream 上训练线性/MLP（hidden=64, ReLU）/circular 探针预测结果的个/十/百位。采用 little-endian 约定（低位在前）使生成顺序与进位方向一致，保证梯度奖励与任务需求对齐；big-endian 消融则引入前瞻性依赖，检验无直接梯度压力时模型是否会因任务强制需求而间接编码未来信息。
- **文献调研协议**：检索 ACL/EMNLP/NAACL/EACL 2024–2025 标题含 math/numer/number/arithmetic 的论文，人工筛选 120 篇，统计是否明确报告数值分词策略及跨模型比较是否控制该变量。

## 实验与结果
- **数据集与任务**：从头训练合成 3 位整数加法数据（$x+y\leq999$，结果均匀采样），固定 500 样本 held-out 测试集；10 个随机种子，学习率与 weight decay 网格搜索。
- **性能与训练动态**：$M_F$ 在所有种子与超参下稳定收敛至满分；$M_H$ 收敛不可靠且精度显著更低（最佳超参下 exact match 约 0.853，个/十/百位准确率分别为 0.857/0.922/0.964），印证单次生成完整三位数难度远高于逐位生成。
- **解耦结论**：$M_{F_{in},H_{out}} \simeq M_H$ 且 $M_{H_{in},F_{out}} \simeq M_F$，任务表现与训练曲线严格跟随输出分词 regime，与输入分词无关。
- **内部表示（探针）**：碎片化输出模型（$M_F, M_{H_{in},F_{out}}$）在残差流中仅能解码第一位（个位），十位/百位维持接近随机水平；整体输出模型（$M_H, M_{F_{in},H_{out}}$）在最后一层同时可解码全部三位，完全符合最小计算假设。
- **Big-endian 消融**：当任务需向前看（进位传播方向与生成顺序相反）时，碎片化输出模型在高层亦能以上 Chance 水平解码未来数位（第二位从 0.11→0.29/0.69，第三位从 0.10/0.18→0.13/0.56），且相邻位可解码性更高，表明模型会因任务依赖被动编码所需信息，但强度弱于直接监督。
- **文献调研结果**：120 篇中仅 11 篇（9.2%）明确报告数值分词策略；其中 83 篇（69%）在未控制 regime 的情况下直接比较整体/碎片化模型，存在系统性混淆风险。
