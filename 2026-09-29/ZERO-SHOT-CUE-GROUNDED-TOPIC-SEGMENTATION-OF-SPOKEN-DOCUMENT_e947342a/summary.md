# 论文速读：ZERO-SHOT-CUE-GROUNDED-TOPIC-SEGMENTATION-OF-SPOKEN-DOCUMENT

## 一句话总结
提出一种无需训练的零样本切分框架 CGS，通过提取显式的话题开场线索定位边界；当线索不足时，自动回退至由第一阶段推断出的文档结构（阶段、边界信号、预计时长）引导的语义切分。该方法在六个基准数据集与六个大语言模型骨干上全面优于现有基线，对 ASR 噪声鲁棒且 API 成本较低。

## 研究问题与动机
- 口语文档缺乏标题等显式结构，话题边界需从话语过渡或主题转换中推断，而现有方法难以自适应跨度极大的切分粒度（如 YTSeg 中位长度仅 12.9 句，ICSI 高达 241.0 句，相差 18.6 倍）。
- 现有 LLM 切分方法多直接预测边界列表、递归分割或生成目录，未显式锚定“话题开启线索”，易将次要转折误判为新话题（过度切分）或忽略实质性话题转换（切分不足）。
- 传统无监督方法依赖词法衔接下降或固定阈值/段落数，泛化性受限；近期 LLM 基线在长转录稿上输出 Token 消耗大、API 成本高。
- 亟需一种无需任务特定标注、能同时利用显式线索与隐式语义结构、且能自适应不同文档长度的零样本切分方案。

## 核心贡献（创新点）
- 提出两阶段零样本切分框架 CGS，Stage 1 提取显式话题开场线索并判断可靠性，Stage 2 在证据不足时调用结构引导的语义回退；与现有方法直接预测边界列表或递归分割不同，本工作首次将边界定位显式锚定于话题开启短语。
- 引入段数范围与结构指导（阶段划分、边界信号、预计时长）作为软约束，使模型能自适应跨度极大的切分粒度；与固定阈值或超参数控制的传统方法相比，本方法无需针对特定语料调整切分粒度。
- 验证了保留原文引文（quote）对提升边界预测置信度的关键作用，并通过消融证明两阶段协同优于单一阶段或仅索引输出；与仅依赖表层词法或逐句意图分类的基线相比，本方法兼顾显式线索与隐式语义漂移检测。
- 实现低输出 Token 消耗与高边际性能收益，在六个骨干模型上均以极低成本达到最优宏观指标；与 DEF-DTS 等逐句推理或 TOC PROMPT 等长文本生成方法相比，本工作通过线索过滤与选择性回退显著降低了 API 调用成本。

## 方法详解
- **Stage 1（线索抽取与可靠性判定）**：输入带编号的完整转录稿，提示 LLM 识别并原文引用每个话题开场短语及其所在句索引，输出结构化 JSON。同时给出线索可靠性标签（reliable / uncertain / unreliable）及是否需要语义回退。若需回退，额外输出：建议段数范围（下限 `max(1, n−1)`，上限 `n+1`）、结构阶段划分（phases）、边界信号描述（boundary signals）、预计单段时长范围（秒）。
- **直接路由（Direct Route）**：若无需 fallback，CGS 丢弃越界索引，直接以有效线索句索引集合作为边界集合 $B_{\text{cue}} = \{0\} \cup \{i : (i, q) \in C\}$。
- **Stage 2（条件语义回退）**：传入完整转录稿、段数范围及 Stage 1 的结构指导。LLM 据此识别语义层面的话题转换并放置边界，不强制依赖显式过渡词。为抑制过碎切分，对相邻边界句索引差 $\le 2$ 的进行合并。
- **提示策略**：全流程使用统一提示词，不暴露数据集名称、不进行任何微调或提供标注示例，真正实现训练无关（training-free）零样本推理。

## 实验与结果
- **数据集**：YTSeg (n=1,448, 中位 12.9 句)、ICSI (n=75, 241.0 句)、AMI (n=129, 66.0 句)、MeetingBank (n=28, 72.6 句)、QMSum (n=20, 28.6 句)、SIM (n=100, 91.6 句)。
- **评估指标**：$P_k$ (↓)、WindowDiff (↓)、Boundary $F_1$ (↑，容差 ±2 句，每真实边界至多匹配一次)。
- **骨干模型**：Gemini-3.1-Flash-Lite、GPT-5.6-Terra、Qwen3.6-27B、Gemma-4-26B-A4B、Qwen3.5-9B、Qwen3.5-4B。
- **主要结果**：CGS 在六个数据集、全部三个指标上均取得最优（或第二优），宏观平均 $P_k$=0.208、WD=0.257、$F_1$=0.508，显著领先最强基线 SEGMENTLLM（$P_k$=0.307, $F_1$=0.412）。80–93% 文档仅凭 Stage 1 即可完成切分。
- **成本与效率**：CGS 输出 Token 约为 SEGMENTLLM 的 1/4，API 成本位列第二低（21.87 USD/1,000 文档），精度与经济性兼顾。
- **消融实验**：移除 Stage 2 回退（FORCED CUES）或使用仅索引不带引文（Cue indices only）均导致性能下降；保留段数范围与结构指导对 Stage 2 性能提升最关键。
- **ASR 鲁棒性**：在 Whisper-large-v3 生成的 AMI、ICSI、YTSeg 噪声转录稿上，CGS 在三类语料上均全面优于 SEGMENTLLM（如 AMI $F_1$: 0.512 vs 0.420）。
