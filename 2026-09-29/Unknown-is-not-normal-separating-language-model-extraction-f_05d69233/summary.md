# 论文速读：Unknown-is-not-normal-separating-language-model-extraction-f

## 一句话总结
本文提出将临床风险评分的"信息提取"与"决策逻辑"分离：先用 LLM 进行三态提取（存在/缺失/未知），再由确定性代码计算分数在未知输入下的上下界，仅向医生询问能改变决策类别的信息。实验表明该策略在相同准确率下将提问量减半，且彻底消除了低分率漏诊（under-triage）。

## 研究问题与动机
1. **现有基准的致命缺陷**：MedCalc-Bench 等主流评测将病历中未提及的发现默认视为"正常/缺失=阴性"（missing-equals-normal），但"未记录咯血"不等于"无咯血"，会系统性地低估风险。
2. **LLM 端到端交互表现不佳**：前沿 LLM agent 在信息收集中要么过早断言（premature commitment），要么提出无法改变决策的不相关问题，且在嘈杂医生场景下准确率显著下降。
3. **临床决策的关键是类别而非精确分数**：如 HEART 评分 0–3 为低风险、4–6 为中度、≥7 为高风险，只要分数范围不跨越阈值，即可安全下结论，无需追问所有缺失项。

## 核心贡献（创新点）
1. **三态提取 + 确定性代码求解的分工设计**：将信息抽取与评分决策解耦——LLM 负责输出三态事实（present/absent/unknown）及置信度，代码负责计算分数上下界并判断决策是否已确定，与现有端到端 agent 形成本质区别。
2. **基于分数边界的"决策相关"提问策略**：仅当某个未知输入的取值变化可能改变最终风险类别时才发起追问，从根本上消除无关问题，而 ask-all 策略近 50% 的问题无法改变决策。
3. **系统性地量化"缺失=正常"假设的危害**：首次在同一实验框架下对比 bounds 策略与 missing-equals-normal 假设，证明后者以"高 headline 准确率"掩盖了 8.5% 的低分率漏诊。
4. **验证小模型替代前沿模型的可行性**：9B 本地模型（Qwen3.5-9B）作为提取器即可达到 oracle 级准确率（99.8%），而 agent 需在每轮调用前沿模型。

## 方法详解
- **三态提取**：对每个输入项，提取器返回状态（present/absent/unknown）、值、单位、最简短原文引证及置信度；任何引证非原文精确子串的声明被拒绝并归为 unknown。
- **分数边界计算**：确定性代码将数值型输入按评分截点划分为区间，枚举所有未知输入的可达分数集合，当且仅当唯一区间对应单一风险类别时判定决策已确定。
- **决策相关性问题判定**：一个未知输入是 decision-relevant 当且仅当存在某种未知输入的完成方式，使得该输入的不同取值导致不同风险类别。例如：HEART 已得 2 分、肌钙蛋白未知（0–2 分）时，可能分数 2–4 跨越低/中危，故肌钙蛋白被追问；若已得 0 分则不追问。
- **提问策略**：按信息价值（value-of-information）排序，每次只问一个决定相关问题的未知项，每获回答后重新计算边界。
- **置信度校准**：采用温度缩放（temperature scaling）和等渗回归（isotonic regression）对提取器置信度校准。
- **缺失=正常基线**：将缺失输入当作"正常"处理，与 MedCalc-Bench 约定一致，作为安全对照。

## 实验与结果
- **数据集**：6 个评分计算器（HEART、CURB-65、qSOFA、PERC、Wells PE、Cockcroft-Gault），各 200 例合成急诊病例（共 1,200 例），30% 输入被故意隐藏，50% 病例的设计意图是"类别由病历无法确定"；另有 559 例脏笔记配对及 584 例 MedCalc-Bench Verified 真实病例报告。
- **提取器**：Oracle（完美提取）、Claude Haiku 4.5、Qwen3.5-9B（本地）、Claude Opus 5.5（作为 agent）。
- **理想条件下（Clean Notes + 理想医生）**：
  - Bounds 策略准确率 **99.4%**，与 ask-all 持平，但平均提问数仅 **0.92**（ask-all：1.78，减少 48%），无关问题率 0%。
  - Missing = normal 准确率达 **91.2%**，低分率漏诊 **8.5%**（95% CI 7.1–10.2），40% 提前断言。
  - Agent（Opus 5.5）准确率达 99.6%，但 9.5% 问题无关，0.2% 提前断言。
- **嘈杂医生条件下**：
  - Bounds 策略准确率 **87.0%**，仍优于 Agent 的 **83.5%**（p<0.001），零提前断言；Agent 提前断言率达 2.7%。
- **小模型验证**：Qwen3.5-9B 提取器配合 bounds 策略达到 **99.8%** 准确率（oracle 级别）。
- **真实病例（MedCalc-Bench）**：584 例中仅 **52%**（48–56%）能从病历确定类别（HEART 仅 13%）；在 missing = normal 约定下类别正确率仅 **69%**（HEART 22%）。

## 相关工作脉络
1. **MedCalc-Bench（Khandekar et al., 2024）**：当前临床评分评测基准，采用"缺失=正常"假设，本文证明该约定严重高估了从病历直接计算评分的可行性（真实确定率仅 52%）。
2. **ClinDet-Bench（Watanabe et al., 2026）**：评估 LLM 在临床决策中的"确定性判断"能力，但未涉及主动提问，本文在此基础上补充了交互式提问维度。
3. **MediQ（Li et al., 2024）与 AgentClinic（Schmidgall et al., 2024）**：评估诊断对话中的信息收集，但面向开放式诊断而非结构化评分，两者在输入空间（固定计算器 vs. 自由诊断）和终止条件上不同。
4. **CRAFT-MD（Johri et al., 2025）**：评估 LLM 在患者交互任务中的临床使用，侧重对话质量而非评分准确性，本文聚焦评分计算场景的安全边界。
5. **MedMCP-Calc（Zhu et al., 2026）**：通过 MCP 集成评估 LLM 在医疗计算中的表现，但仍依赖端到端模型决策，未将提取与计算分离。

## 局限性与未来方向
1. 合成病历由 LLM（Claude Sonnet 5）生成，风格比真实病历更整洁，存在模型同族偏差（约 3.2 个百分点的准确率优势）。
2. 医生噪声模型较简化（固定噪声率、固定 per-case 噪声模式），与实际临床沟通存在差距。
3. 真实病例分析中无法测试提问策略（因缺乏交互环境），仅能评估静态计算性能。
4. 校准依赖自报告置信度，Claude 模型通过 headless Claude Code 运行，实际部署时置信度估计可能需要重新校准。

## 研究启发与可借鉴点
1. **"提取-决策分离"架构的可迁移性**：凡涉及"从非结构化文本到结构化评分/规则"的场景（如药物剂量计算、筛查工具评分），均可借鉴此分离设计，用代码承担可确定性的推理，避免 LLM 隐式填补空白。
2. **分数边界方法（score bounds）作为安全性原语**：不仅适用于临床评分，也可推广至任何具有明确阈值区间的规则系统，作为"不确定时不预测"的安全机制。
3. **小模型 + 规则代码的组合竞争力**：9B 本地模型 + 确定性代码即达前沿 agent 水平的准确率，提示在安全敏感场景中"小模型提取 + 规则推理"可能是比"大模型端到端"更优的工程选择。
4. **对评测基准的批判性审视**：本文揭示了 MedCalc-Bench "缺失=正常"假设的系统性偏差，后续研究应报告"病历实际可确定类别的比例"而非仅 headline 准确率。

## 关键术语表
**Missing-equals-normal（缺失=正常）**：将病历中未提及的输入默认视为正常/阴性的处理约定，本文证明该约定导致系统性低分率漏诊。

**Score bounds（分数边界）**：在未知输入的所有可能取值下，评分可达的最小与最大值的范围，用于判断当前信息是否足以确定风险类别。

**Three-state extraction（三态提取）**：将每个输入项分类为 present（有值）、absent（明确缺失）或 unknown（未记录），取代传统的二值（有/无）分类。

**Under-triage（低分率漏诊）**：将实际属于较高风险类别的患者错误归类为较低风险类别，是本文强调的最关键安全隐患。

**Premature commitment（过早断言）**：在决策类别尚未被文档事实充分确定时，LLM 就急于给出结论。

**Value-of-information ordering（信息价值排序）**：在多个待问未知项中，优先询问对缩小分数边界贡献最大的输入。
